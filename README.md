## Como executar o projeto

Para executar o projeto Bico de Tucano, é necessário configurar o banco de dados antes de iniciar a aplicação.

### 1. Configuração do banco de dados

1. Localize a pasta `Banco`, dentro do projeto.
2. Abra o arquivo `.sql` utilizando o MySQL Workbench.
3. Execute o script SQL para criar e configurar o banco de dados.
4. Certifique-se de que o banco de dados foi criado corretamente antes de prosseguir.

### 2. Executando a aplicação

1. Abra a solução do projeto no Visual Studio.
2. Verifique se a conexão com o banco de dados está configurada corretamente.
3. Execute o projeto pelo Visual Studio.
4. Acesse a aplicação pelo navegador.

### 3. Acesso como administrador

Após essas etapas, o sistema estará pronto para utilização.
